## 2024-05-24 - Missing Keyboard Accessibility on Interactive Table Rows
**Learning:** Table rows (`<tr>`) used as clickable buttons in the RequestList lack basic keyboard accessibility (`tabIndex`, `onKeyDown`) and visual focus indicators, breaking navigation for keyboard/screen reader users.
**Action:** When implementing custom interactive elements like clickable rows, always add `tabIndex={0}`, handle "Enter" and "Space" in `onKeyDown`, add an `aria-label`, and provide `focus-visible` styles to ensure they are fully accessible.
