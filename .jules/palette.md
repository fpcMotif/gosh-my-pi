## 2025-03-01 - Add Accessibility to Custom Interactive Table Rows
**Learning:** Custom interactive elements like `<tr onClick>` strictly require additional manual implementations to be keyboard accessible. Adding just `onClick` excludes users who navigate using a keyboard (e.g., using "Tab" to focus, and "Enter" or "Space" to select). Screen reader users or users employing assistive technology could miss out completely if elements aren't correctly focusable and usable.
**Action:** When creating custom interactive elements (e.g. table rows or custom divs acting as buttons/links), always explicitly set `tabIndex={0}` to allow focus. Handle `onKeyDown` and bind interactions correctly to "Enter" and "Space" keys (using `e.preventDefault()` on space to avoid unwanted window scrolling). Also include visible CSS utility classes (like `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[var(--accent-cyan)] focus-visible:bg-[var(--bg-hover)]`) to ensure screen-focused navigators explicitly see where the focus currently lies.
