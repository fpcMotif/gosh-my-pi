## 2024-05-30 - Accordion Accessibility and Focus Visibility in ModelsTable
**Learning:** Accordion UI patterns missing `aria-expanded` and `aria-controls` fail to relay their structural state to screen reader users, and missing `focus-visible` styles limit operability for keyboard users navigating through long data lists (like `ModelsTable`). Providing inline interactive elements (like the expand arrow button) with matching ARIA bindings and `focus-visible:outline-none focus-visible:bg-[var(--bg-hover)]` solves this gracefully without polluting standard pointer-driven UI.
**Action:** When implementing expandable rows in similar React tables, immediately generate matching `id` attributes for the button and the expanded panel region to provide `aria-labelledby`, `aria-controls`, and `aria-expanded` bindings, and pair it with focus-visible CSS utility classes.
