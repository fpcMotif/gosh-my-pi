## 2024-03-24 - Interactive Table Row Accessibility
**Learning:** Found an accessibility issue pattern specific to this app's components where custom interactive elements (e.g., `<tr onClick>` in `RequestList.tsx`) lacked manual keyboard accessibility, preventing keyboard users from interacting with the rows. Custom table rows used as interactive buttons need keyboard support to be fully usable. Do not use `role="button"` on `<tr>` elements to avoid overriding native table semantics.
**Action:** Always implement manual keyboard accessibility by adding `tabIndex={0}`, an `onKeyDown` handler for 'Enter'/'Space' keys (calling `e.preventDefault()` on Space to prevent page scrolling), and `focus-visible` utility classes for clear visual focus states (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[var(--accent-cyan)] focus-visible:bg-[var(--bg-hover)]`).
