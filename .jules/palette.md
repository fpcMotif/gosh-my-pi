## 2025-05-15 - Accessible custom interactive elements
**Learning:** Custom interactive elements (e.g., `<tr onClick>`) lack native keyboard focus and interaction by default, reducing accessibility for screen reader and keyboard users. Space bar scrolling needs to be prevented when activating these elements.
**Action:** When creating custom interactive elements in React (like a clickable table row), ensure manual keyboard accessibility by adding `tabIndex={0}`, an `onKeyDown` handler for 'Enter' and 'Space' (calling `e.preventDefault()` on Space to prevent page scrolling), and `focus-visible` utility classes (like Tailwind's `focus-visible:outline-none focus-visible:ring-2`) for clear visual focus states without relying on native button semantics that might override or break the surrounding markup semantics.
