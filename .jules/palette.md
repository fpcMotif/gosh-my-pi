## 2024-06-08 - Keyboard accessibility on `<tr onClick>` elements
**Learning:** Custom interactive elements (e.g., `<tr onClick>`) in the React frontend must implement manual keyboard accessibility. They are not naturally focusable and don't natively trigger click events on 'Enter' or 'Space'. Also, 'Space' normally scrolls the page, so it must be explicitly prevented.
**Action:** When adding `onClick` to elements like `<tr>` or `<div>`, always add `tabIndex={0}` to make it focusable, an `onKeyDown` handler that catches 'Enter'/'Space' (with `e.preventDefault()` for 'Space') to trigger the click logic, and `focus-visible` utility classes so the focus state is visually clear to keyboard users. Do not use `role="button"` on `<tr>` elements to avoid overriding native table semantics.
