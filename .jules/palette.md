## 2024-05-27 - [Keyboard Accessibility for Table Rows]
**Learning:** Custom interactive elements like `<tr onClick>` in React tables inherently lack keyboard accessibility. While adding `tabIndex={0}` allows them to receive focus, they require an explicit `onKeyDown` handler to respond to standard activation keys (Enter and Space), otherwise keyboard-only users cannot interact with them. Additionally, a clear `focus-visible` outline or highlight is necessary to indicate focus.
**Action:** When creating or modifying non-button interactive elements (e.g., `<div>`, `<tr>`, `<li>` with `onClick` handlers), ensure they have `tabIndex={0}`, an `onKeyDown` handler that explicitly checks for `e.key === "Enter" || e.key === " "` (and prevents default scrolling for Space), and a `focus-visible` styling class (like `focus-visible:outline-none focus-visible:bg-[var(--bg-hover)]`).
