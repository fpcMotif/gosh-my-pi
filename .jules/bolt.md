## 2024-05-17 - Promise Coalescing for Redundant Backend Syncs
**Learning:** In the stats dashboard, the frontend makes concurrent API requests on load (`/api/stats`, `/api/stats/recent`, `/api/stats/errors`). Each request triggers `syncAllSessions()` on the backend, leading to redundant concurrent disk I/O (listing files, parsing `.jsonl` session files) because each request independently starts the synchronization process before any can finish.
**Action:** Use promise coalescing (storing the ongoing Promise in a module-level variable and returning it to subsequent concurrent callers) for expensive read-only or synchronization operations. This ensures the work is only done once, regardless of how many concurrent frontend requests trigger it, significantly reducing unnecessary backend load.
