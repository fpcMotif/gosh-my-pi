## 2025-05-18 - Avoid loading full files into memory when extracting slices
**Learning:** When parsing appended data in `.jsonl` session files, calling `await Bun.file(path).bytes()` reads the entire file into memory before slicing with `.subarray(start)`. This is a performance bottleneck for large log files and creates unnecessary memory pressure. Furthermore, attempting to slice beyond the file's size directly can lead to issues, and treating all errors as `ENOENT` during a full file read hides other potential I/O problems.
**Action:** Always compute bounds manually using `const size = Bun.file(path).size`. Because `size` is `0` if the file does not exist, this automatically handles `ENOENT` cleanly without needing a `try/catch` block checking for it. Then, calculate `const start = Math.max(0, Math.min(fromOffset, size))` and read only the needed chunk using `await Bun.file(path).slice(start).bytes()`.
