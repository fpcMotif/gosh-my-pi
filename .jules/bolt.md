## 2024-06-25 - Bun.file().slice().bytes() vs subarray
**Learning:** In Bun, reading an entire large file with `await Bun.file(path).bytes()` and then using `.subarray(start)` to extract appended data is an anti-pattern. It loads the entire file into memory, which gets progressively slower for large log/session files. `Bun.file(path).slice(start).bytes()` is significantly faster for tailing files (from ~3400ms down to ~100ms in benchmarks). Furthermore, reading `Bun.file(path).size` gracefully returns 0 for non-existent files without throwing `ENOENT`, while `bytes()` will throw.
**Action:** When extracting trailing sections of files in Bun, calculate size manually, clamp the offset, and prefer `slice(start).bytes()`. Ensure `bytes()` calls are still wrapped in `try/catch` to handle `ENOENT` races (TOCTOU).
