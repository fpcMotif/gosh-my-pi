## 2025-05-11 - [Coalescing Concurrent API Requests]
**Learning:** In the `stats` package, the frontend (`App.tsx`) makes multiple concurrent API requests on load (e.g., `/api/stats`, `/api/stats/recent`, `/api/stats/errors`). The backend middleware executes a synchronization process (`syncAllSessions`) which leads to multiple parallel file scans and heavy SQLite aggregations (`getDashboardStats`).
**Action:** Always check if heavy I/O or aggregation operations in backend endpoints are susceptible to concurrent triggers from a single client. When true, utilize promise coalescing (request deduplication) using a module-level variable to store the pending promise and clearing it in a `finally` block to ensure multiple requests wait on the same execution rather than redundant work.
