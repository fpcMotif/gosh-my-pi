- Optimizing dict.get(key, []) inside loops: Python's dict.get(key, default) evaluates the default argument every time it's called. Inside tight loops, `dict.get(key, [])` creates a new empty list on every iteration where the key doesn't exist, and even when it does (since argument is evaluated before calling). Replacing this with an `if key in dict: for item in dict[key]:` pattern avoids these unnecessary allocations, leading to >2x performance improvements for those sections.
