## 2026-05-20 - Promise Coalescing for Redundant I/O Avoidance
**Learning:** The stats dashboard's backend API was prone to redundant filesystem I/O because `syncAllSessions` was being called indiscriminately by multiple API routes requested simultaneously by the frontend (`/api/stats`, `/api/stats/recent`, `/api/stats/errors`). Since `syncAllSessions` recursively crawls session directories using `fs.readdir`, these concurrent identical tasks caused a lot of unnecessary I/O overhead.
**Action:** When an API request performs a heavy read-only or synchronization operation (like recursive file system scanning), utilize a simple promise coalescing (request deduplication) pattern. Maintain a module-level variable for the active promise and return it immediately if concurrent requests come in while an operation is already pending.
