## 2024-05-30 - Promise coalescing for concurrent backend syncs
**Learning:** In `packages/stats`, `syncAllSessions` is frequently called on various API endpoints (e.g. `/api/stats`, `/api/stats/recent`, etc). If multiple requests hit the server concurrently, this results in multiple concurrent runs of `syncAllSessions` which performs heavy file system I/O and SQLite operations. The instructions explicitly highlight this pattern: "To prevent redundant file I/O and database queries from concurrent frontend requests against the backend API, apply promise coalescing (request deduplication) for heavy read-only or synchronizing backend operations."
**Action:** Applied promise coalescing to `syncAllSessions` in `packages/stats/src/aggregator.ts` to deduplicate concurrent requests.
