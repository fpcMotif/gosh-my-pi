## 2024-05-18 - Promise Coalescing for Backend API Operations
**Learning:** In the stats service, concurrent API requests from the frontend could trigger redundant backend operations (e.g., syncing all sessions to the local database, which is heavily I/O bound). The existing code awaited `syncAllSessions` on multiple endpoints (like `/api/stats` and `/api/stats/recent`). Because these routes are hit concurrently when the dashboard loads, multiple syncs were executing needlessly.
**Action:** Used the promise coalescing pattern (request deduplication) for heavy, read-only/synchronizing operations. By caching the in-flight Promise and clearing it out on `.finally()`, all concurrent requests wait for a single execution to finish. Next time I encounter a backend with parallel requests to the same heavy function, I will ensure promise coalescing is applied.
