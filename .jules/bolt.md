## 2024-06-02 - [Parallelizing Configuration File Loading]
**Learning:** We identified a pattern in `packages/coding-agent/src/discovery/builtin.ts` where multiple loaders (like `loadSlashCommands`, `loadRules`, etc.) were sequentially reading directories or files using a `for...await` loop. This codebase relies heavily on the `Promise.all` + `.map()` pattern for I/O-bound initialization to optimize performance, as previously demonstrated in other parts of the monorepo (e.g., in `packages/coding-agent/src/extensibility/custom-tools/loader.ts`).
**Action:** Replaced sequential `for (const x of await ...)` loops with parallel `Promise.all(configDirs.map(...))` to ensure configuration discovery stages don't block each other. Always look out for sequential `.map()` or `for..of` iterations containing async I/O when initializing components in this architecture.
