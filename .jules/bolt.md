## 2024-05-18 - Bun File Slicing Optimization
**Learning:** Using `await Bun.file(path).bytes()` and then slicing the `Uint8Array` via `.subarray()` reads the entire file into memory which is slow for large logs/sessions. Using `Bun.file(path).slice(start).bytes()` performs significantly faster (e.g. ~50x speedup in benchmarks reading the tail of a 100MB file) because it only reads the requested bytes from disk. However, care must be taken: `Bun.file(path).size` must be used to compute the bounds, but `.size` on a missing file returns 0 without throwing `ENOENT`, whereas `.bytes()` throws `ENOENT` if the file doesn't exist.
**Action:** When extracting data from the end of append-only logs like `.jsonl`, manually compute the file size bounds with `Bun.file(path).size` to avoid out-of-bounds, then use `Bun.file(path).slice(start).bytes()` in a `try/catch` to safely catch `ENOENT` and prevent TOCTOU races.
