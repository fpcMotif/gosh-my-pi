## 2024-06-19 - Parallelize module loading in extensibility loaders
**Learning:** Sequential `for...of` loops used for loading modules, extensions, and hooks bounded by I/O (like `Bun.file().json()` or dynamic `import()`) can severely impact initialization performance. In custom loaders (`custom-tools`, `custom-commands`, `extensions`, `hooks`), concurrent resolution via `Promise.all` combined with a sequential mapping of results reduces overall latency while preserving critical logic like name-conflict detection.
**Action:** When working on loader modules or discovering resources, explicitly map array iterations over asynchronous operations into an array of promises, resolve them concurrently using `Promise.all`, and then sequentially iterate over the outcomes for validation and state accumulation.
